## What is GameLaunchAI?

GameLaunchAI is an open-source AI tool that helps indie game developers create a complete commercialization strategy. Input your game details, and our multi-agent system generates a professional playbook covering:

- 💰 **Monetization Strategy** — IAP design, ad placement, pricing (not just "add ads")
- 🌍 **Market Fit Analysis** — Which regions to launch in, CPI/LTV benchmarks
- 📣 **Go-to-Market Plan** — UA channels, budget allocation, KPI targets
- 🌐 **Localization Priority** — Which languages first, ROI estimates

> Built by a game marketer who got tired of seeing great games fail at monetization.

## Why GameLaunchAI?

Most indie devs know their monetization *options* (IAP, ads, premium) but don't know which one fits *their* game, or how to design it properly.

Existing tools solve one piece — CAS.ai does ad mediation, GameAnalytics does data. **Nobody connects the full decision chain**: what model → what market → what channels → what languages.

That's the gap GameLaunchAI fills.

## 中文

### GameLaunchAI 是什么？

GameLaunchAI 是一个开源的 AI 工具，帮助独立游戏开发者制定完整的商业化策略。输入你的游戏信息，多 Agent 系统会为你生成一份专业的商业化方案：

- 💰 **变现策略** — 内购体系设计、广告位规划、定价策略
- 🌍 **市场定位** — 适合哪些地区发行、CPI/LTV 基准数据
- 📣 **推广方案** — 渠道选择、买量策略、KPI 设定
- 🌐 **本地化建议** — 语言优先级排序、ROI 估算

> 由游戏营销从业者打造，用 AI 把行业经验开源给每一个独立开发者。
